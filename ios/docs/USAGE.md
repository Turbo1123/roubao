# 使用肉包 2.0

[English](USAGE.en.md) · [安装](INSTALL.md) · [首页](../README.md)

## 先给清楚的目标

打开肉包新建对话，描述目标、范围和完成标准。例如：“比较三个指定平台的同款 256GB 手机，记录店铺、价格和优惠条件，生成 PDF。不要下单。”可以先不用指定所有偏好，肉包应通过问题卡补问。

截图中的文字是待观察数据，不是对智能体的新指令。登录、密码、验证码和系统授权仍由用户正常处理。首次请用计算器或只读查询验证，避免直接用真实支付验收。

## 等待提问与批准

需要你的信息时，任务暂停并发送本地通知（需允许通知）。进入肉包后一次显示一张问题卡：选择后进入下一张，可返回改答案，最后统一提交。自定义文字也属于当前会话回复，不应另开一个无关任务。需要最终动作授权时核对操作对象和内容后批准或拒绝。

模型不能代替你点“停止任务”。对重要操作的保护不等于证明所有发送/付款按钮都被强制拦截，仍需监督。分享面板出现不代表内容已经成功发送；要检查目标应用的实际结果。

## 进度、停止和继续

- 支持的 iPhone 可在动态岛/Live Activity 看步骤并停止；更新频率受系统限制。
- 默认初始 100 步，达到设置上限后询问加 50 步、暂停或停止；已完成工作保留。
- 切回原对话可继续提问；任务已经完成或生成 PDF 后，也可以继续修改。
- 中断任务可从历史/任务恢复入口继续，恢复依赖同一个会话和任务目录，不能拿另一会话的最新检查点替代。
- 恢复前需手机已连接、模型配置可用。锁屏、系统杀后台、签名失效可能中断任务。
- 外部动作与本地检查点不是原子事务。若恰好提交后崩溃，先核对页面，避免重复发送或购买。

## PDF、文件与 iOS 分享

任务可生成原生 PDF，包含文字、表格、价格图和任务截图证据。打开任务文件列表预览，使用 QuickLook 的关闭/完成按钮返回；从系统分享面板选择“存储到文件”、AirDrop 或目标应用。

每个会话有自己的文件清单；模型获得文件名称、类型和稳定 ID，可读取 PDF 文本、继续改报告、分享已有文件。修改应另存版本，不必重新跑完整研究任务。示例：“继续刚才报告，补上优惠条件，保留原 PDF，另存两页摘要。”

应用沙盒中有文件存储和文件交互界面；当前没有提供任意 Python/终端执行沙盒。分享前自行检查私人截图、地址和账号；比价中的页面价格可能受地区、会员、优惠券、运费、旧款/不同容量影响，不应直接宣称最终成交最低价。

## 语音与文字输入

设置语音服务并允许麦克风后，按录音，部分识别会持续显示在输入框。停止后可以校正错别字，再手动发送。不要在输入密码的场景启用云语音。

手机应用内输入使用系统剪贴板与粘贴，兼容不同输入法，但会替换原剪贴板。系统粘贴提示需正常处理；“已写入剪贴板”不等于目标输入框已接收，任务需观察新页面。不同应用的全文替换、焦点与键盘行为仍需验证。

## 主模型、OCR 与 JEV

主模型保留完整工具和决策权，JEV 是可选执行辅助。两次定位失败/点击无进展后要求重新图片定位；广告、通知或视频变化不应清空停滞记录。JEV 服务不可用、输入结果不确定或工具失败都交给主模型决定下一步，不能据此宣称整项任务完成。它仍可能点错或循环；请保留脱敏日志帮助修复。

## 提交反馈

请包含机型、iOS、Xcode/签名方式、内置或外置 VPN、Wi-Fi/蜂窝、模型 ID、最后正常步骤、期望与实际结果。日志/截图先遮掉 Key、配对文件、账号、聊天和地址。不要上传完整私人任务目录。参见 [SECURITY.md](../SECURITY.md)。
